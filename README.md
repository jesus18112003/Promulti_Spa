Age of Empires II - Civilizations Hub

¡Bienvenido al Portal de Civilizaciones de Age of Empires I! Este proyecto es una aplicación web interactiva diseñada para que los estrategas puedan explorar a fondo las bonificaciones, unidades únicas y tecnologías de cada civilización del juego.

Este proyecto fue desarrollado bajo estándares de diseño responsivo y optimización de experiencia de usuario (UX).

Características

Exploración Interactiva: Visualiza detalles específicos de cada civilización (Incas, Búlgaros, Polacos, etc.).
  Diseño Premium: Interfaz inspirada en la estética medieval del juego, con acabados en dorado y fondos oscuros.
  Side Panel Inteligente: Un panel lateral responsivo que adapta su tamaño según el dispositivo (Desktop/Mobile).
  Multimedia: Inclusión de temas musicales únicos y visualización de arquitectura (castillos) y maravillas.
  Filtros Dinámicos:** Clasificación de civilizaciones por regiones geográficas.
  Optimización UX:
  Bloqueo de scroll de fondo al abrir detalles.
  Scroll personalizado "estilo AoE" integrado.
  ero desbordamiento lateral en dispositivos móviles.

Tecnologías Utilizadas

HTML5: Estructura semántica.
CSS: Diseño personalizado, Flexbox, CSS Grid y animaciones de transición.
JavaScript: Lógica de filtrado, manipulación del DOM y gestión de estados del panel lateral.


Vista Responsiva

El proyecto ha sido optimizado para funcionar en:
Desktop: Panel lateral elegante de 400px.
Mobile: Panel adaptativo al 100% del ancho de pantalla para garantizar legibilidad total en dispositivos pequeños.
